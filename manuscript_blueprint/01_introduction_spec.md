# Introduction Specification

## Opening problem
Agentic systems transform model outputs into multi-step actions, tool calls, persistent state changes, and interactions with other agents. Safety analysis therefore needs to distinguish *what risk exists* from *where safety broke in the objective-to-action pathway*.

## Gap
Existing frameworks already address lifecycle risk management, domains, frontier capabilities, agent failure modes, governance, tool security, and multi-agent risk. The narrower gap is a case-level, evidence-grounded way to distinguish:
- objective/role mismatch,
- recognition failure,
- recognized-but-not-enacted safety constraints,
- oversight-dependent behavior,
- runtime failure to stop/defer,
- relational/system externalities,
- distinct outcome/feedback failure.
